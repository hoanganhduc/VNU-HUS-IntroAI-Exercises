## Classroom50 workflow


## Required submission

Complete `submission.md` by following the authorized exercise statement. Put
the complete required response between its `BEGIN` and `END` markers, and
replace the starter placeholder.

Run the public completion check:

```bash
python3 check_submission.py
```

When it passes:

```bash
git add submission.md
git commit -m "Complete Exercise 1.1"
git push
gh student submit
```

## What the checker verifies

The checker verifies file safety, marker uniqueness and order, a nonempty
response, and placeholder removal. It does not judge any response, evidence, or
conclusion.

```text
100/100  complete submission
0/100    incomplete submission
```
