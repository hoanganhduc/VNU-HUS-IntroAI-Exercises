# Week 5 — Logic Programming with PROLOG scaffolds

**Bibliographic references:** Wolfgang Ertel, *Introduction to Artificial
Intelligence*, 3rd ed. (2025), Exercises 5.2, 5.3, 5.5, and 5.8,
pp. 90–91.

This public package does not include or restate the exercises and does not
include the book-derived support examples used by a particular course
deployment. Obtain authorized statements and any authorized support material
separately.

## Required submission

```text
plan2.pl
ones.pl
fib.pl
fib01.pl
answers.md
```

Complete the blank targets and response blocks according to the authorized
statements. Students may run their own Prolog tools; the completion checker does
not execute Prolog.

```bash
python3 check_submission.py
git add plan2.pl ones.pl fib.pl fib01.pl answers.md
git commit -m "Complete the Week 5 PROLOG exercises"
git push
gh student submit
```

Read the shared [Classroom50 workflow](docs/CLASSROOM50-WEB-UI.md). The checker
verifies safe regular files, noncomment target content, and completed response
blocks only.

```text
100/100  complete submission
0/100    incomplete submission
```
